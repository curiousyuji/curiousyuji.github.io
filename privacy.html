プライバシーポリシー

最終更新日：2026年10月24日

このアプリについて

このアプリは、運営者（curiousyuji）が自分自身の Google Tasks を、自分の AI アシスタントから読み書きするための個人用ツールです。一般向けのサービスではありません。

取得するデータ

運営者本人が許可した Google アカウントの Google Tasks のデータ（タスクリスト、タスクの内容・期限・状態など）だけを、Google Tasks API を通じて扱います。第三者のデータは収集しません。

データの利用目的

取得したデータは、運営者本人のタスク管理（表示・追加・更新・完了）のためだけに使います。広告やその他の目的には使いません。

第三者への提供

取得したデータを第三者に共有・販売することはありません。

保存

Google の認証トークンは、運営者本人が管理するサーバーに保存し、第三者には渡しません。

Google API Services User Data Policy

このアプリによる Google API から受け取った情報の利用は、Limited Use の要件を含む Google API Services User Data Policy に従います。

アクセスの取り消し

アクセス権は Google アカウントの「サードパーティ製のアプリとサービス」 からいつでも取り消せます。

Privacy Policy

Last updated: October 24, 2026

About this app

This app is a personal tool that lets its operator (curiousyuji) read and update his own Google Tasks from his own AI assistant. It is not a service for the general public.

Data accessed

The app only handles Google Tasks data (task lists and tasks, including their content, due dates and status) of the Google account the operator himself has authorized, through the Google Tasks API. It does not collect any data about third parties.

How data is used

The data is used only for the operator's own task management (viewing, adding, updating and completing tasks). It is not used for advertising or any other purpose.

Sharing

The data is never shared with or sold to third parties.

Storage

Google authorization tokens are stored on a server managed by the operator and are not given to third parties.

Google API Services User Data Policy

This app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from Third-party apps & services in your Google Account.
